# Talent photos

Drop real headliner photos here to replace the illustrated poster portraits.
Each card automatically uses the photo if the file exists, and falls back to
the illustration if it doesn't — no code changes needed.

## Exact filenames (must match)

| File                          | Talent            |
|-------------------------------|-------------------|
| `fahad-al-butairi.jpg`        | Fahad Al Butairi  |
| `mo-amer.jpg`                 | Mo Amer           |
| `nemr.jpg`                    | Nemr              |
| `ramy-youssef.jpg`            | Ramy Youssef      |
| `joe-achkar.jpg`              | Joe Achkar        |

## Specs

- **Format:** JPG (or rename the `<img>` src to `.png`/`.webp`).
- **Shape:** portrait, roughly **3:4** (e.g. 900 × 1200 px). Faces look best
  framed head-and-shoulders near the top — the card crops from the top.
- **Look:** dark / high-contrast shots sit best in the marquee bulb frame.

## Important — licensing

Only use photos you have the right to use:

1. **Freely-licensed** images (Creative Commons on Wikimedia Commons, etc.) —
   keep attribution. Add credits to `CREDITS.md` in this folder.
2. **Official press / promoter kit** photos cleared for promotion.
3. Photos **you own** or have a licence for.

Do **not** drop in random images scraped from Google/Instagram — those are
copyrighted, and using a real person's photo for a show they aren't actually
booked on is a likeness/rights problem. This lineup is currently a **demo**.
